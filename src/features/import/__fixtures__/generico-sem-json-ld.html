Verde Logística — Curitiba, PR — Híbrido

Sobre a vaga

A Verde Logística está montando a plataforma de dados que sustenta o roteirizador de entregas. Você vai desenhar e manter os pipelines que alimentam os modelos de previsão de demanda, trabalhando lado a lado com o time de ciência de dados.

O que você vai fazer

  • Construir pipelines de ingestão em Python e Airflow
  • Modelar o data warehouse em BigQuery
  • Garantir qualidade e observabilidade dos dados

Requisitos

  • Experiência com Python e SQL em produção
  • Familiaridade com orquestração (Airflow, Dagster ou equivalente)
  • Vivência com dbt é diferencial

Benefícios

  • Plano de saúde e odontológico
  • Auxílio home office
  • Day off no aniversário
